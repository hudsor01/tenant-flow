public.rent_charges columns:
  id uuid pk default gen_random_uuid()
  lease_id uuid not null references public.leases(id) on delete cascade

  description text
  reverses_id uuid references public.rent_charges(id)   -- reversal = exact negation of referenced row

public.rent_receipts columns:
  id uuid pk default gen_random_uuid()

  owner_user_id uuid not null references public.users(id) on delete cascade

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated client → rent_charges/rent_receipts | Owner inserts receipts/manual lines/reversals directly (untrusted owner_user_id claim crosses here) |
| pg_cron (service_role) → rent_charges | Scheduled generation writes system charges without a user session |
| any writer → booked ledger amounts | Immutability boundary — amounts must never change after insert |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-55-01 | Spoofing/Elevation | rent_charges/rent_receipts INSERT | mitigate | INSERT policy `with check (owner_user_id = (select auth.uid()))` — client cannot forge another owner's rows |
| T-55-02 | Information disclosure | cross-owner ledger read | mitigate | SELECT policy `using (owner_user_id = (select auth.uid()))`; verified by dual-client RLS test (55-03) |
| T-55-03 | Tampering/Repudiation | edit/delete a booked amount | mitigate | No UPDATE/DELETE RLS policy PLUS `BEFORE UPDATE OR DELETE` guard trigger raising 0A000 for every writer incl. service_role (RLS alone insufficient — Pitfall 3) |
| T-55-04 | Elevation | end user calls generate_rent_charges() to fabricate charges | mitigate | `revoke all from public, anon, authenticated; grant execute to service_role`; SECURITY DEFINER `set search_path = public` |
| T-55-05 | Tampering (integrity) | money-scale 100x corruption | mitigate | `numeric(10,2)` scale + single `rent_amount::numeric(10,2)` conversion; grep gate in verify + static test in 55-03 |
| T-55-06 | Tampering | duplicate/inflated charges on cron re-run | mitigate | partial unique index `(lease_id, period_start) where type='rent'` + `ON CONFLICT DO NOTHING` idempotency |
| T-55-SC | Tampering | npm/pip/cargo installs | accept | No package installs this phase (RESEARCH Package Legitimacy Audit — pure Postgres + existing rails); nothing to vet |
</threat_model>
