## Two deploy traps this project has already hit

1. **`supabase functions deploy` 401s.** Known, standing, documented. The workaround is
   `bun scripts/deploy-edge-functions.ts`.
2. **MCP `deploy_edge_function` corrupts non-ASCII source.** The MCP path takes the
   function body as a model-emitted string, so any character the model re-emits imperfectly
   ships to production. That is why the deploy script reads from disk, and why
   verification must be a post-deploy `get_edge_function` read rather than trust in the
   call that appeared to succeed.
</objective>
