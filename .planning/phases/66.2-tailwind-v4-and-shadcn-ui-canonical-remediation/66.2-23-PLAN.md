Hazards measured while planning (they decide the commit shape):
- **Slot concatenates without twMerge.** `<Button asChild>` merges the child's className through Radix Slot by plain string concatenation. Once Action renders through `Button asChild`, a site that still passes the legacy literal on the default variant carries both `bg-primary` and `bg-destructive`, and CSS order decides the color. So the `alert-dialog.tsx` change and the 16 site migrations MUST land in ONE commit. No commit may contain only one half.
- **No duplicated or contradicting className may remain.** The planning census found only two remaining values: `flex-1` (unit-actions Action and Cancel) and `gap-2` (sign-lease-button Action, subscription-cancel Action). `gap-2` is already in the Button base, so it is dropped. `flex-1` stays on the primitive (upstream shape, D-26), and Slot appends it without twMerge. The legacy `cn(buttonVariants(...), "flex-1")` let twMerge drop the base `shrink-0` (measured in this worktree: `twMerge("shrink-0 flex-1")` gives `flex-1`), so the rendered set of those two buttons gains exactly `shrink-0`, and computed flex-shrink goes from 1 to 0. `flex-1`'s 0% basis should make flex-shrink inert there. Task 3 proves it with a Chromium geometry probe of the unit-actions footer, rather than assuming it. A call-site `shrink` class cannot undo the delta, because `.shrink` compiles before `.shrink-0`. Passing className to Button instead would diverge from the D-26 upstream shape, so it is not used.
- **The ledger measured against the old Button.** The ledger's "class set identical, measured" (C16) was measured against the pre-66.2-22 Button. Under the post-22 contract, the destructive variant also carries `focus-visible:ring-destructive/20 dark:bg-destructive/60 dark:focus-visible:ring-destructive/40`. So the 16 confirmations now show the VD-19 destructive row in dark mode and on focus, exactly like every destructive Button; light-mode at-rest tokens are identical. The test asserts this delta mechanically. The SUMMARY records it for gate 66.2-29, whose allowed set includes VD-19, and for the PR body: UI-SPEC's "no visual change" line for this item holds only against the pre-22 Button.
