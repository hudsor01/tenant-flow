## Notes for 66.2-24 onward

- `AlertDialogAction({ className, variant = "default", size = "default", ...props })` and `AlertDialogCancel({ ..., variant = "outline", ... })`, typed `ComponentProps<typeof AlertDialogPrimitive.Action|Cancel> & Pick<ComponentProps<typeof Button>, "variant" | "size">`. The rendered element is the primitive's `<button>` with `data-slot="alert-dialog-action|cancel"`, `data-variant`, `data-size`.
- A className passed to them is appended unmerged after Button's twMerged classes. Never pass a class that repeats a Button class (e.g. `gap-2`) or contradicts one (colors, `shrink`): use `variant`/`size`. `.shrink` compiles before `.shrink-0`, so a call-site `shrink` cannot undo the base `shrink-0` here.
- A CP-2 fallback (66.2-39) that changes the destructive variant must update `VD19_DESTRUCTIVE_DELTA`.
