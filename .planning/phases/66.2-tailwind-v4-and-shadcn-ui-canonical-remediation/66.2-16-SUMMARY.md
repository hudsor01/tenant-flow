## For 66.2-18 and 66.2-25 (chart-tooltip canonicalizer note)

`src/components/ui/chart-tooltip.tsx` now uses `border-(--color-border)` for the indicator, because the element sets `--color-border` inline to the series color. The two classes are NOT equivalent here; never canonicalize this one back. `src/components/ui/**` is exempt from G8 and the codemod, and the upstream shadcn chart uses the same `border-(--color-border)` form.
