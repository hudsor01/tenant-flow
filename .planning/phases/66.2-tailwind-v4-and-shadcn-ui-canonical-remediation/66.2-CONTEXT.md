## Phase Boundary

This phase fixes every Tailwind v4 / shadcn/ui defect found by the 2026-10-25 measured audit, at its root, and proves each fix by measurement. It leaves the styling layer canonical. Delivery is **six ordered waves on one branch, ending in one PR**:

1. **Visible bugs + permanent guards:** B1–B8, X1, guards G1–G6.
2. **Dead and misleading code, source scoping:** B9–B11, X2–X6, G7.
3. **Canonical shadcn token architecture:** `:root`/`.dark` + `@theme inline`.
4. **Canonical first-party classes:** Tailwind's canonicalizer, G8.
5. **shadcn component sync:** against the new-york-v4 registry, verified claims only.
6. **Owner shell on the canonical shadcn Sidebar.**

The finding IDs (B*, X*, M*, R*, G*) are defined in `.planning/tailwind-shadcn/PLAN.md`. This phase does NOT redesign the product: no new pages, no new navigation entries, no new runtime dependencies, no change to the positioning invariants.
