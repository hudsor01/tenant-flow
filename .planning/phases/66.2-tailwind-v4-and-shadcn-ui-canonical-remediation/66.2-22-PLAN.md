Purpose: UIC-07. The repo Button predates the v4 registry contract: it has no data attributes, so parents cannot key on `[data-slot=button]`; it uses the v3 2px offset ring; its outline and dark surfaces differ from upstream; and its icons have no default size. The canonical Sidebar (W6) and the AlertDialog sync (66.2-23) build on the v4 Button. The auto-size rule `[&_svg:not([class*='size-'])]:size-4` has higher specificity than an icon's own `h-N w-N`, so every explicitly sized icon must move to `size-N` in the same change, or it collapses to 16px. `shrink-0` stops a shrinkable Button from shrinking in a flex row, so those call sites keep today's layout with `shrink`.
