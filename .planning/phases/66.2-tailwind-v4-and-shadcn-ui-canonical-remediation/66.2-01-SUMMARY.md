## Output schemas (downstream contract)

- `render-<label>.json`: `{ label, tokenListSource, tokenCount, fontVarsSource, fontVars, fontVarsOn, globalError: { fontVarsOn }, fonts: { light|dark: { html, body, fontMono, codeTag, fontDisplay } }, secondaryPixel: { light: [r,g,b], dark: [r,g,b] }, pairs: [{ name, outer, inner, fg }], contrast: { light|dark: { <name>: ratio } }, touch390: { switch|buttonSecondary|iconButton|iconButtonSize8|input|inputH9: { width, height, padding, minHeight } } }`. stdout is the same object (2-space JSON); the tokens path goes to stderr.
- `tokens-<label>.json`: `{ light: { <token>: [r,g,b,a] }, dark: {...} }` (unchanged format).
- css-parity report: `{ baseline, current, strict, total, identical, changed, counts: { spacing-equivalent, color-inline, added, removed, unclassified, intended:<label>... }, lists: { <class>: [candidate] }, unclassified: [{ candidate, baseline, current, normalizedBaseline, normalizedCurrent }] }`; stdout = `counts`; exit 0/1/2.
- `screens-<label>/manifest.json`: `{ label, baseUrl, startedServer, captures: [{ set, route, theme, width, file, status, finalUrl, themeApplied, consoleErrors }], skipped: [{ set, route, reason }], owner?: { skipped } | { error } }`; a failed capture also carries `error`. `file` = `<set>/<slug>-<theme>-<width>.png`.
- `diff-<A>-vs-<B>.json`: `{ summary: { identical, changed, sizeChanged, missingInA, missingInB }, files: [{ name, sizeA: [w,h], sizeB: [w,h], changedPixels, changedRatio, bbox: { x, y, width, height } | null }], missing: { inA, inB } }`; highlight PNGs at `diff-<A>-vs-<B>/<name>`.
- `probes-<label>.json`: `{ meta: { tailwindVersion, scannedFiles, candidates, bundleBytes }, results: { <id>: { light, dark } } }` with the per-probe fields listed in the component-probes.mjs header; a probe may add `pageErrors` and, on failure, carries `{ error }`.
