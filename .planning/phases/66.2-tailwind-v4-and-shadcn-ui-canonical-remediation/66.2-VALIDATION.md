## Sampling Rate

- **After every task commit:** lefthook runs gitleaks, the frozen lockfile check, `bun run lint`, `bun run typecheck` and `CI=true bun run test:unit -- --coverage`, which includes every guard landed so far. The task also runs its own targeted quick command.
- **After every plan:** `audit.mjs` for the metric the plan moves; `render-check.mjs <plan>` whenever tokens, fonts or contrast change; and the plan's Chromium probe.
- **After every wave (exit gate):** the full PLAN.md §7 protocol (CONTEXT D-43):
  - audit;
  - `css-parity.mjs`;
  - token-snapshot diff;
  - `bun run validate:quick`;
  - `SKIP_ENV_VALIDATION=true bun run build`;
  - the screenshot matrix (`screens.mjs`: light/dark × 390/1280; public pages + owner pages via `loginAsOwner`);
  - an Aikido scan of changed first-party code.

  Waves 1 (E-22) and 6 also run `--project=owner-axe`.
- **Before `/gsd:verify-work`:** the full suite is green; CI `checks` / `e2e-smoke` / `rls-security` are green; the owner-axe set, including `app-shell-sidebar.spec.ts`, passes; the coverage ratchet holds; and the PR has passed the perfect-PR gate (two consecutive zero-finding cycles on the frozen state).
- **Max feedback latency:** 60 s per task commit (lefthook); the wave gate is bounded by `next build`.
