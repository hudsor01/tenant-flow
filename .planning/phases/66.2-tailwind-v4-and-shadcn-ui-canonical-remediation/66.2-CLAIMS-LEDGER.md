## Plan implications (binding on research and planning)

Where a ledger correction changes a CONTEXT decision, the corrected fact wins:

- **C10 narrows D-26.** Only sonner's `theme` guard is still needed; upstream `toast.tsx:17` fails TS2375. With radix-ui 1.8.1, upstream `dropdown-menu` (`checked`) and `slider` (`value`) compile cleanly, so take them as upstream ships them and drop those two local workarounds.
- **C8 refines D-27.** A sync without a root provider would throw at only **4 production sites in 2 files**: `property-table-row.tsx:201/215/229` and `financial-overview-stats.tsx:48`. The fix is unchanged (a root `<TooltipProvider>` in the same change); the 5 local providers become redundant and are removed.
- **C9 extends D-29.** The `naming-conventions.test.tsx` rewrite must also replace the outline `border-input` assertion at L37. The `<30 classes` assertion fails only because the local `min-h-11` is kept, so rewrite it rather than delete it.
- **C12a is a visible change and needs owner review.** GridPattern's background has been invisible on every `PageLayout` page (25 importing files; `showGridPattern` defaults to true) and on `/auth/confirm-email` and `/auth/update-password`. Fixing the classes makes it appear. The PR must carry before/after screenshots for those surfaces. If the owner rejects the restored grid, the fallback is `showGridPattern` defaulting to false, not leaving broken classes in place.
- **C12c sharpens D-30.** BlurFade's decisive defect is the inverted `inView` semantics at `blur-fade.tsx:86`; even with every class generated, none of its **175 call sites** would animate. Today nothing is visibly wrong: content is fully visible, and the wrapper applies only `transition-all` + `will-change: transform`. **Remediation hazard:** any fix that starts content hidden must be proven never-invisible. That means content still appears without JS, with `prefers-reduced-motion`, and with an `IntersectionObserver` that never fires. Restoring motion is optional; never-invisible is mandatory.
- **C12d.** twMerge strips LoadingSpinner's `text-(--font-*)` classes before render, so the `size` prop never changes text size. The fix needs Tailwind's length type hint, `text-(length:--…)`, and the D-14 tailwind-merge config must classify it as a font size.
- **C12b.** Add `--animate-border-beam` to `@theme`, plus `@keyframes border-beam` animating `offset-distance`, so the 23 beams animate and honor their `duration` prop.
- **C2 widens D-28.** The gridlines are wrong in **light mode too** (#ccc instead of the border token). The inert dot selector also leaves a 2px white ring on hover dots. That covers 12 grids in 8 files and 18 Area/Line series. The token-stroke fix covers both themes.
- **C15.** The deep import is at `chart-tooltip.tsx:5-9`. `NameType` has no public alias, so add a local alias as upstream does. When moving to public types, delete the `vitest.config.ts:53-56` deep-path alias and `src/test/mocks/recharts-tooltip.ts`.
- **C14 corrects the data-slot scope.** The work is the 22 files with no data-slots, plus `AlertDialogAction`/`AlertDialogCancel`. `toggle` ships no DOM part and needs nothing, and `avatar`, `field` and `item` need no data-slot work.
- **C16 corrects the count.** There are **14** hand-rolled destructive `AlertDialogAction` sites: 13 literal strings, plus `confirm-dialog.tsx:44-49`, which covers 7 ConfirmDialog uses and must pass `variant`. Two more sites use `cn(buttonVariants({variant:"destructive"}))`: `subscription-cancel-section.tsx:273` and `units/components/unit-actions.tsx`.
- **C3.** The palette's search row renders at 44px instead of 48px, and the 48px input overflows it. The upstream `CommandDialog` className (D-26) fixes it.
- **C5.** Besides forwarding `value`, give the bulk-import Progress an accessible name; axe rates this serious.
- **C7** is low and cosmetic: corner artifacts and an off-token surface on the three date-picker popovers. It's fixed by the calendar class plus the popover data-slot.
- **S8 is a live defect, observed directly.** Every sidebar link, the wordmark included, underlines on hover at ≥1024px. Wave 6 fixes it with D-49's neutralizers; the before/after screenshots must show it.
- **S7** is broader than claimed: the step-5 target is off-screen across the whole drawer range (<1024px), and below 768px the popover itself is off-screen too. D-39 covers both.
- **S9** has extra detail: the unlayered rule also re-pads the footer Settings button, the search pill and the close X. Wave 1 (B2) fixes all of them at once.
- **S15** counts **13** owner-surface files, not 12. D-33 (the lg breakpoint) holds: a 768px sidebar measured tablet grids 25-36% narrower.
- **All other claims (CONFIRMED)** stand exactly as stated in the raw reports.
